# v1.0.0 — Initial Baseline

Baseline pertama website katalog/pricelist aplikasi premium.

## Customer
- Pink/cute responsive storefront.
- Search + category filtering.
- Flexible dependent variants.
- Normal/promo price and Ready/Sold Out state.
- Product-level quantity mode (`multiple` default / `single`).
- Buy Now to WhatsApp.
- Persistent cart to WhatsApp.
- Cart price/status reconciliation against current catalog data.

## Admin
- Single-owner authentication.
- Product/category management.
- Mobile-first product forms.
- Editable option/value names.
- Flexible variant combination builder.
- Quick Edit price/promo/status.
- Product/category touch drag sorting.
- Product image and store logo upload.
- Store and WhatsApp template settings.
